# telefon-yedek

Public artifact repository.

## Boundary

Only intentionally public, non-sensitive artifacts belong here. Do **not** store:

- assistant memory or notes;
- phone backups containing personal data;
- credentials, API keys, tokens, recovery codes, or signing material;
- keystores or private keys;
- application databases or exported account data;
- local `.env` files.

APK files may be stored only when they are intentionally public and contain no embedded private credentials.
